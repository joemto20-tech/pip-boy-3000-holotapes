WHAT THE PIP-BOY ACTUALLY READS

Every graphic is 2 bits per pixel, packed four pixels to a byte, most significant pair first, row-major with no header and no padding. Level 0 is black, level 3 is the brightest phosphor. A .IMG file is the same pixel data behind a three or four byte Espruino header (width, height, bpp | transparent flag, [transparent index]).

PAGE LAYOUT

A world file is not one big image — it is a stack of pre-rendered screens. Page index is row * columns + column. Sunscar uses camera origins X 0,240,480,720,960 and Y 0,196,392,588,784. Rot's Crossing and Dogtown use X 0,240,480,720,960,1192 and Y 0,196,392,588,645 — the final row and column deliberately overlap their neighbours so the camera never runs off the edge. This kit stitches and re-slices that for you; just work on the flat map.

WORKFLOW

1. Paint or photograph a map at the world's exact pixel size.
2. WORLDS tab → drop the image → tune brightness/contrast until the ground sits on level 3 and structures fall to level 0-1 → EXPORT .BIN.
3. MAKE COLLISION → trace → tidy by hand → WALK TEST from the spawn point → EXPORT .BIN.
4. Copy both into HOLO/BIGIRON/ and add them to metadata.json.
